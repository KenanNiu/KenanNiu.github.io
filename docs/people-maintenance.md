# People and RAM sources

The People page contains Group Lead, Postdoctoral Researchers, PhD Researchers and Alumni sections. Group membership was specified by Kenan Niu. Public names, research interests, professional email addresses and portraits were checked against the RAM staff directory and individual profiles on October 14, 2026.

Edit `assets/data/people-data.js` to maintain members. Use `group` values `lead`, `postdoc`, `phd` or `alumni`. Alumni currently has no records and intentionally renders only its heading. Keep member roles accurate and preserve the RAM profile link and source-photo URL when updating portraits.

Local portrait files are the original RAM 500px square thumbnails, with no face editing. `maintenance/people-sources.json` records their origins. Public source credit appears on the People page, and each member links directly to their RAM profile.

Both full and concise versions use a sky-blue theme. Stylesheet references include a version query to refresh cached files; update that version when future palette changes need a cache refresh.
