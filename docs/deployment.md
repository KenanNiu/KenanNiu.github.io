# Deployment Guide

## Personal GitHub Pages

GitHub Pages personal sites are served from a repository named:

```text
<github-username>.github.io
```

For example, if the GitHub username is `kenanniu`, the repository should be:

```text
kenanniu.github.io
```

Push the website folder contents to that repository root. GitHub Pages will use `index.html` as the entry page.

## Project GitHub Pages

If you prefer to keep this website inside another repository, configure GitHub Pages in the repository settings and publish from the selected branch/folder.

## Recommended First Deployment

Use the personal site repository. It gives the clean URL:

```text
https://<github-username>.github.io
```

## After Publishing

GitHub Pages can take several minutes to update after a push. If the site does not appear immediately, wait and check the repository's Pages settings or Actions page.
